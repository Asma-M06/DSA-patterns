Whenever solving recursion problems :
• there is always a base condition that ends your recursion
• always remember there are 2 things either you include the solution set(like an array elements)
     or you exclude it not with every problem but most of the problem has it

For instance consider the following template:

1. when simple recursion : lets say function returning fibonacci series for nth index

f(n){

    if(n<=1){  ----------->> Base condition 
        return n;
    }

    return f(n-1)+f(n-1); --------->>recursion taking place
}

lets see the recursion tree for this:

consider we do for n = 5, 
series go like 0 1 1 2 3 5 8 13 ...
                         |
         index 0 1 2 3 4 5


                                f(5)---->>5
                              3  /  2
                            f(4) + f(3)
                            /
                           /
                       2  /  1
                     f(3) + f(2) 
                     /\
             1      /  \   1
                   /    \
                f(2) + f(1)
                /\
        1      /  \  0
              /    \
            f(1) + f(0)
            

---here we used multiple recursion call i.e f(n-1) and f(n-2) that is very common in bigger complex problems like nqueens


2. Now we see problem of inclusion and exclusion of solutionset

lets us consider subsequence problem :
so we have an array [3,1,2] we need subsequence which follows continuous order this problem is solved using powerset but here we use recursion

subsequence wil be [],[3,1,2],[3],[1],[2],[3,1],[3,2],[1,2]

alright so function looks like this:

subsequence(ind,arr,seq,n)
{
    if (ind == n) --------------->>Base condition
    {
        for (auto it : seq)
        {
            cout << it << " ";
        }
        if (seq.size() == 0)
        {
            cout << "{}";
        }
        cout << endl;
        return;
    }
    seq.push_back(arr[ind]);---------------->>include the arr element so we add
    subsequence(ind + 1, arr, seq, n);---------->>call when we include
    seq.pop_back();------------------------->>exclude the element
    subsequence(ind + 1, arr, seq, n);--------->>call when exclude
}
